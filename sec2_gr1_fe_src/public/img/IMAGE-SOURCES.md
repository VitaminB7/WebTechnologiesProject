# Homepage images

`residence.jpg` is an AI-generated architectural illustration created for the
CONDONG CONDO project. It depicts a fictional condominium and is not a
photograph of an actual CONDONG property.

`welcome.jpg` is a separate AI-generated daytime courtyard illustration with
two residential buildings and a pool, created for the Welcome section. It
also depicts a fictional condominium.

Both images are stored locally with the website so they can be committed with the
source code and does not depend on an external image host at runtime.
